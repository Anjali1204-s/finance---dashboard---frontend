# 💰 Finance Dashboard

## 📌 Project Overview
This is a Finance Dashboard web application that helps users track their income and expenses. It provides real-time balance updates, transaction history, and visual representation using charts.

---

## 🚀 Features
- Add Income and Expense
- Automatic Balance Calculation
- Transaction History
- Pie Chart Visualization
- Currency Converter (API Integration)
- Clean and Responsive UI

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js (for charts)
- External API (Currency Converter)
